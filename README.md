# Empathy Engine

Create an app, SentimentDetector, which detects a person's sentiments based on the sentence written by the person and lists out the potential emotions that match the user's mood as a dictionary-based sentiment analysis. Also use LLMs and APIs. The app must be able to handle rare cases of dual emotion in sentence and also do multi-modal integration which recognizes sentiments of words and emojis used in the sentence.

This project was built with [Lovable](https://lovable.dev).
